# CRIAÇÃO DE E-COMMERCE — INVICTOS CALÇADOS

Crie do ZERO um e-commerce moderno, sofisticado e comercial para a marca **INVICTOS CALÇADOS**, localizada em Nova Soure — Bahia.

Este projeto será utilizado inicialmente como **DEMONSTRATIVO COMERCIAL PARA APRESENTAÇÃO AO CLIENTE**, mas toda a estrutura deve ser pensada para posteriormente ser integrada a **WordPress + WooCommerce**.

NÃO criar uma landing page.

Criar uma experiência completa de loja virtual.

---

# 1. REFERÊNCIA VISUAL DA MARCA

Use como referência visual as imagens fornecidas nesta conversa, especialmente:

* perfil do Instagram da Invictos Calçados;
* identidade visual preta e dourada;
* logotipo "INVICTOS CALÇADOS";
* fachada e interior da loja;
* publicações de produtos;
* comunicação de moda feminina e masculina;
* conteúdos de localização;
* fotografias de bolsas, calçados, roupas e acessórios.

A identidade visual deve transmitir:

**sofisticação + confiança + moda + acessibilidade + loja física consolidada.**

A marca NÃO deve parecer uma loja de luxo inacessível.

Também NÃO deve parecer uma loja genérica criada por inteligência artificial.

O resultado precisa parecer um e-commerce desenvolvido profissionalmente para uma loja física real.

# 2. DIREÇÃO DE DESIGN

Paleta principal:

* Preto profundo: #080808
* Preto secundário: #111111
* Dourado principal: #C9A227
* Dourado claro: #E3C45C
* Off-white: #F5F3ED
* Branco: #FFFFFF

Evitar excesso de sombras.

Evitar cards excessivamente arredondados.
